# ML System: Wine Classifier with FastAPI, Docker, Streamlit, and MLflow

A complete ML system built on top of Practical Task 6. Trains a Random Forest classifier on the Wine dataset, serves predictions through a FastAPI backend, provides a Streamlit frontend for user interaction, and tracks all experiments via MLflow.

## Project Structure

sis3-bro/
├── train.py                  # Trains the model and logs to MLflow
├── main.py                   # FastAPI backend (serves predictions)
├── frontend.py               # Streamlit frontend (user interface)
├── model.joblib              # Trained model (generated by train.py)
├── requirements.txt          # Python dependencies
├── Dockerfile                # Containerizes the FastAPI backend
├── mlruns/                   # MLflow experiment storage (auto-generated)
└── README.md



## Dataset

Wine dataset from scikit-learn — 178 samples, 3 cultivar classes.
The model uses the 5 most informative features: `alcohol`, `flavanoids`, `color_intensity`, `od280/od315`, `proline`.

## Model

- **Algorithm:** Random Forest Classifier
- **Hyperparameters:** `n_estimators=100`, `max_depth=5`, `random_state=42`
- **Test accuracy:** ~97%

## System Architecture

[User Browser]
        ↓
[Streamlit UI :8501]  →  HTTP POST  →  [FastAPI :8000]  →  [model.joblib]
                                                                ↓
                                                            prediction returned



MLflow tracks every training run and stores model versions in the Model Registry.

## Setup

Create a virtual environment and install dependencies:

```bash
python -m venv .venv
source .venv/bin/activate       # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## How to Run

### 1. Train the model

```bash
python train.py
```

This trains the classifier, logs parameters/metrics/artifacts to MLflow, registers the model as `WineClassifier`, and saves `model.joblib` for the API.

### 2. Open MLflow UI (optional, for inspection)

```bash
mlflow ui
```

Visit `http://localhost:5000` to see experiment runs, metrics, and registered model versions.

### 3. Run the FastAPI backend

```bash
uvicorn main:app --reload
```

API runs at `http://localhost:8000`. Interactive docs at `http://localhost:8000/docs`.

### 4. Run the Streamlit frontend (in a second terminal)

```bash
source .venv/bin/activate
streamlit run frontend.py
```

Frontend opens at `http://localhost:8501`. Use the preset buttons to load example inputs for each wine class, or enter values manually.

### 5. Run with Docker (API only)

```bash
docker build -t ml-api .
docker run -p 8000:8000 ml-api
```

## API Endpoints

- `GET /` — health check
- `POST /predict` — accepts `{"features": [5 floats]}`, returns `{"predict": <0|1|2>}`

### Example request

```json
{"features": [13.7, 3.0, 5.5, 3.15, 1115.0]}
```

## MLflow Integration

- **Experiment:** `wine-classifier`
- **Logged parameters:** `n_estimators`, `max_depth`, `num_features`
- **Logged metrics:** `accuracy`, `f1_score`
- **Logged artifacts:** trained model
- **Registered model:** `WineClassifier` (versioned automatically on each run)
